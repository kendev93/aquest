# 归档目录

这里放**已经完成使命、但值得留档**的文档，不参与日常查阅。

## 收什么

| 类型 | 说明 | 例子 |
| --- | --- | --- |
| 已实施的方案 | 功能已上线，方案文档只在需要回溯「当初为什么这么定」时查阅 | `factor-test-plan.md` |
| 调研快照 | 某一时点的外部调研结论，结论已固化进代码或后续文档 | `datasource-survey-2026-09-20.md` |
| 代码审查记录 | 某轮审查的发现与复核结论，问题已修复或已另有定论 | `code-review-2026-10-05.md` |

## 不收什么

- 仍在维护的设计/口径说明（留在 `docs/` 顶层）
- 尚在排期、未实施的功能方案（留在 `docs/feature-backlog.md` 里作为条目，不要单独建文件）

## 引用约定

归档文档里指向 `docs/` 顶层文档用 `../`，指向同目录归档文档直接写文件名。
新建归档文档时请顺手把正文里的旧路径改掉——本目录里的链接不会自动跟着移动。
