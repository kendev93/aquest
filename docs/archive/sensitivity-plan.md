# 参数敏感性分析（backlog #3）

条件研究最后交出来的是一句话结论：**某个指标在某个切点上，命中样本的胜率更高**。
这句话里最脆弱的是"某个切点"——它可能是真的抓住了一段区间，也可能只是碰巧最好的一个数。

区分两者的办法就是把它往两边挪一点，看优势塌不塌：

- **台地**：邻域里挪一点、再挪一点，优势还在 → 这条条件抓的是区间，切点选得随意点也无所谓。
- **悬崖**：只有这一个数好用，邻域一挪优势就掉、甚至反过来 → 典型的过拟合形状。

产出是每张候选一条邻域曲线（5 个偏移点），读法是"这条结论靠不靠谱"最直观的证据。

---

## 一、扰动什么：在分位空间挪，不在阈值算术空间挪

backlog 原话是"阈值上下浮动 ±10/20%"。落地时改成**分位偏移**，两个原因：

1. **量纲**。一个指标的阈值可能是 10.2，另一个是 0.03，"±10%"对两者的含义完全不同，
   跨候选之间没法比。
2. **有一半条件根本没有常数**。挖掘同时产出 `指标 ≥ 常数`（分位阈值）和 `指标A > 指标B`
   两类条件，后者没有任何常数可挪。

统一做法：任何条件都归约成「**差值序列 + 阈值**」。

| 条件 | 差值序列 | 阈值 |
| :--- | :--- | :--- |
| `X ≥ c` | `X` | `c` |
| `X ≤ c` | `−X` | `−c` |
| `A > B` | `A − B` | `0` |
| `A < B` | `B − A` | `0 |

归约之后，`命中 ⇔ 序列 ≥ 阈值` 对所有条件成立，扰动就是在**这个序列的分位**上挪：
`q' = q ± Δ`，`阈值' = quantile(序列, q')`。

偏移量的含义因而统一为**"松一点 / 紧一点"**，与量纲无关：

- `Δ < 0` → 阈值降 → 命中更多 → **更宽松**
- `Δ > 0` → 阈值升 → 命中更少 → **更严格**

默认 5 个点：`−0.10, −0.05, 0（基点）, +0.05, +0.10`。
`q` 夹在 `[0.01, 0.99]`，避免推到两端后命中集合退化成"几乎没有"或"几乎所有"。

---

## 二、用什么度量：挖掘自己的口径

每个偏移点重算的必须是**和候选表同一口径的数**，否则"峰值 1.42、邻居 1.31"没法读。
所以复用挖掘的计分方式，一步都不改：

- 命中样本按交易组去重（一组最多贡献一个样本，取首次命中）→ 与挖掘的 `support_count` 一致
- 胜率 = 去重后命中样本的均值 → 与 `outcome_rate` 一致
- 基线胜率 = 全量可评估样本的分组等权胜率 → 与 `baseline_rate` 一致（不随阈值变）
- `lift = 胜率 / 基线胜率`

**基点用原始阈值直接算**（不是按分位重建的阈值），所以候选表里那条 lift 和邻域表基点那一格
是同一个数，同源可核对。

---

## 三、怎么读：保持率，不给评分

绝对 lift 跨候选不可比，所以给出**保持率**：

```
保持率 = (邻域 lift − 1) / (基点 lift − 1)
```

- `1.0` = 优势一点没掉
- `0.5` = 优势掉了一半
- `< 0` = 优势打反了（邻域比基线还差）

**基点没有优势时（`基点 lift − 1 ≤ 1e-12`）保持率给 `None`，不硬算**——和衰减比、
滚动一致性同一个立场：分母没有意义就不给数，宁可空着。

不给"稳健度评分"。只给事实：

- `stable_offsets / evaluated_offsets`：几个偏移**仍然有提升**（lift > 1）
- `median_retention` / `worst_retention`：中位 / 最差保持率
- 每个点的阈值、命中数、胜率、lift 原样返回，用户自己看

**不把"没样本"算成"没通过"**：命中样本数 < `min_trades`、或阈值退化到恒真（条件不再
筛掉任何样本）的点标 `insufficient` / `degenerate`，从分子分母里一起剔掉，并在 note 里
写明剔了几个。否则一个稀疏指标会被读成"这条条件在邻域全部失效"，而事实只是那个切点
没抓到足够样本。

---

## 四、在哪个数据上算：挖掘样本（寻优期）

**这一点必须写清楚，否则结论会被误读。**

邻域曲线是在**挖掘样本（寻优期）**上重算的，而这个切点本身也是在寻优期挑出来的。
所以曲线回答的是：

> **这个切点是不是噪声尖峰？**

而不是：

> 样本外还能不能行？

后者由验证期约束、留出期复验和滚动复验负责，三者是互补的，不是替代关系。
（真要做样本外的邻域，得把验证期的样本也建出来——那要每只股票多跑一轮回测并回传
特征矩阵，成本不低，先不做。若后面做，接口不动，只换入参。）

---

## 五、为什么不配置化

邻域重算是纯向量化运算（每候选 5 个点，各一次布尔比较 + 一次分组去重），
相对整轮研究的成本可以忽略，所以**默认开、不留开关**——少一个旋钮，也少一处
历史还原要处理的字段。

偏移量写死为 `±0.05 / ±0.10`（分位）。若后面有理由调，改成配置即可，数据结构不用动。

后端 `condition_research/sensitivity.py`：`build_sensitivity` / `build_sensitivity_for_samples`，
每个候选的 `sensitivity` 字段挂到结果上。

前端在候选表下加「参数敏感性」区块：每候选一行，5 个格子按保持率上色（红 = 优势打反，
深 = 保持得多，灰 = 未计入），右侧给「仍有提升 N/M」「中位」「最差」三列事实数字。
