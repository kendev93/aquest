# 单指标 / 因子检验页（backlog #5）

## 一、它回答什么

> 这个指标能不能把股票按「未来 N 天的收益」排出个先后？

和已有的两处横截面研究的区别，必须先说清楚，否则就是第三个长得一样的页面：

| | 标签 | 问的是 |
| :--- | :--- | :--- |
| 条件研究 · 排序推荐 | 单股回测产生的**成交**收益率 | 在**信号日**里，谁该优先占槽位 |
| 波段研究 · 指标研究 | 波段**事件**（是否临近反转） | 哪个指标在波段启动前出现异常值 |
| **因子检验（本页）** | 未来 N 日**收盘价收益**（每天每只都有） | 这个指标本身有没有预测力 |

前两者都是「有条件才看的样本」；因子检验是**无条件全样本**——每一天、每一只股票都在样本里。
这是量化研究里最标准的那个因子检验，也是本项目此前唯一缺的正门。

## 二、为什么不直接复用 `score_indicator`

`swing_research/scoring.py::score_indicator` 已经有：每日秩相关 IC、ICIR、整块置换 p 值、噪声门槛、BH-FDR。
看上去搬过来就行，但**不能**：

它的「首尾 20%」证据是

```
top_lift = 头桶命中率 / 全样本命中率
```

这是**命中率的比值**，只在标签是 0/1 事件时成立。本页的标签是收益，可能为负：
全样本平均收益 −0.3%、头桶 −0.1% 时，比值是 0.33 —— 看着像"差了三倍"，实际是**亏得少**，是好事。
符号一翻，结论就反了。（和策略追踪衰减比踩的是同一个坑：分母为负时比值没有意义。）

所以本页自己算，但**复用两个经过验证的公共件**：

- `block_permutations`（整块打乱日期，不是打散单元格）
- `benjamini_hochberg`（31 个指标一起看，必须校正）

秩相关 + Gram 矩阵置换那部分照抄其数学（约 30 行），不另发明一套——
两套 IC 算法给出不同数字是最糟的结果。

## 三、口径（定死的部分）

### 3.1 标签

```
fwd[t] = close[t+h] / close[t] − 1
```

- **收盘价到收盘价**，h 为交易日数。
- 最后 h 个交易日没有未来，标签为 NaN，这些天**自动不进横截面**（不是记成 0）。
  为了让它们有数据可算，读行情时把结束日期往后多读一段；研究窗口本身不扩大。
- 不含交易成本、滑点、停牌、涨跌停、流动性约束。**这是因子检验，不是策略回测。**
  这句话必须写在页面上，否则"多空年化 8%"会被当成能拿到手的钱。

### 3.2 信息系数

- 每日横截面：把当天所有有效股票的「指标值」与「未来收益」各自**排名**（并列取平均秩），
  再算秩相关 → 一天一个 IC。
- **独立单位是交易日，不是单元格**。5344 只 × 500 天看着是 267 万个样本，
  但股票共用同一个市场时钟，周二集体反弹则周三的标签基本是同一个故事。
  先按天聚合再统计，才能诚实地做检验。
- 每天有效股票数 < `min_cross_section`（默认 20）的天不参与——三个点的秩相关没有意义。

输出：`ic_mean` / `icir`（= mean/std）/ `ic_positive_rate`（与均值同号的天数占比）。

### 3.3 置换检验（是不是噪声）

整块打乱**日期**（不是单元格）：把第 t 天的指标值配到第 π(t) 天的收益上，重算平均 IC。
打散单元格会保留"同一天"的依赖而只破坏跨天依赖，零分布会窄得离谱，什么都显著。

实现走 Gram 矩阵：`G[t,u]` = 第 t 天指标与第 u 天收益的秩相关，**一次算完**，
之后每次置换只是取一条对角线。否则 200 次置换 × 500 天 = 十万次相关，跑不完。

产出 `pvalue` 与噪声门槛 `ic_threshold`（置换分布 95 分位），
并说明"实测是噪声门槛的几倍"——只给 p 值不够，长序列里几乎什么都过得去。

### 3.4 分层收益（收益铺开还是只在极端）

按当天指标排名切成 5 档，报告每档的平均未来收益。
档位按 IC 符号排序输出：第 1 档 = 你会买的那一组。

- **单调性**：从第 1 档到第 5 档应当递减。有倒挂就报倒挂处数——
  说明收益挤在极端那一档，而不是铺在整个横截面上（那种通常活不到实盘）。

### 3.5 多空组合

每日价差 = 第 1 档平均收益 − 第 5 档平均收益。

- 累计曲线用**累加**不复利：这是每日调仓、持仓期 h 天重叠的价差，
  复合出一个"净值"会凭空放大。
- `t_stat` 按 **N/h** 折算独立样本（重叠窗口会抬高 t 值，不折算就是骗自己）。
- 给 `win_rate`（价差为正的天数占比）与 `max_drawdown`（累计曲线最大回撤）。

### 3.6 前后半段

把交易日切两半，各报一个平均 IC。

**这不是样本外。** 指标是用户给的，但方向（买高还是买低）是看全样本的符号定的，
而"31 个里挑最好的"这件事由 BH-FDR 负责。前后半段一致只说明**不是某一段独撑**，
不代表样本外能复现。页面里照此写。

### 3.7 三条"读数会误导人"的护栏（真机跑通后补的）

第一次真机（sh 全市场 300 只、2024-09→2026-09、horizon=5、100 次置换）跑出来的四个指标
**全部通过 FDR 校正**，但翻到细节会发现三处会把人带沟里的读数。都改了：

1. **"强度可观"不能只看 p 值。** return20 的 IC = 0.063、p = 0.050，看着漂亮；
   但噪声门槛是 0.061，实测只有它的 **1.0 倍**——刚过线而已。
   ⇒ 加 `CLEAR_IC_RATIO = 2.0`：IC 得有噪声门槛的两倍才许说"强度可观"，
   否则说"通过检验（p=…）但仅略高于噪声门槛"。
2. **倒挂计数把平地判成坑。** 分层收益 `0.00563 / 0.00566 / 0.00567 / 0.00606 / 0.00316`
   被报"3 处倒挂"——前三档只差万分之一。⇒ 容差取**整条阶梯跨度的 5%**
   （`LAYER_INVERSION_TOLERANCE`），小于它的上升算平地不算倒挂，实测降到 1 处。
   在噪声上响的警告比没有警告更糟，因为它看着像发现。
3. **排名是真的 ≠ 多空可执行。** 同一个 return20，多空价差为正的天数只占 **54%**。
   ⇒ `win_rate < 0.55` 时 note 补一句"接近抛硬币，扣掉成本未必可执行"。
   没有这句，"通过校正"的徽标会被读成能取出来的钱。

**半段的符号必须留着**：半段对外存绝对值（符号已经用在方向上了），
但"前后半段方向相反"是**符号**的命题——从绝对值上读就永远触发不了。
内部保留符号判断，展示才取绝对值。

**p 值有下界**：N 次置换的最小可能 p 值是 1/(N+1)。用户把 alpha 调到 0.01、
置换只做 100 次时，任何指标都不可能显著；这时 `reason` 直说原因，
而不是让"全部不显著"被读成"这些指标都是垃圾"。

## 四、刻意不做的

- **不给任何"因子评分"或"是否可用"的总评。** 只给事实数字 + 一句话 note，阈值由用户定。
  与衰减比、滚动一致性、参数敏感性同一立场。
- **不做收益曲面 / 参数寻优。** 那是 #3 参数敏感性的活。
- **不做样本外切分。** 见 3.6。
- **不接自定义公式的所有输出。** 沿用 `swing_research/values.py` 的允许清单：
  三个 TDX 公式里只有连续、无量纲的 12 个输出可排（其余是常数 / 脉冲 / 伪装成价格的 EMA）。

## 五、成本与预算

面板形状（指标数 V × 股票数 S × 交易日 D），float32 存值 + float64 存标签：

```
bytes = V × S × D × 4 + S × D × 8
```

全市场 5344 只 × 500 天 × 31 个指标 ≈ 350 MB，可接受。
但全市场 × 5 年 × 31 个指标 ≈ 800 MB，所以照样走**预算三道墙**（沿袭波段研究）：
自身上限 → 可用内存的一半 → 临时目录余量。超了就在跑之前拒绝，并说清撞在哪道墙、
该减哪一项。宁可提前拒绝，也不要跑到一半把后端拖垮（波段研究实测：6 GB 面板打死了 8 GB 容器）。

计算量：两遍读行情（第一遍只建日期轴），每只股票每个涉及的公式算一次；
指标缓存命中时第二遍基本是 IO。31 个指标 × 500 天的秩相关是向量化的，秒级到几十秒。
走**任务 + 轮询**（同策略适配性），不用 SSE——这页不需要中途看部分结果。
