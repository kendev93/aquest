# 新手教程：跑通你的第一个策略

这份教程面向第一次使用 AQuest 的人。它用一条贯穿始终的路径——「有想法 → 筛选 → 验证 → 组合回测 → 往后观察」——带你走一遍完整的研究流程。它不替代 [docs/user-manual.md](user-manual.md)：手册逐页写清每个数字的口径和边界，教程负责让你先走上正确的路。

先说清楚这个工具是什么：一个**日线级别的研究工作台**。它帮你在 A 股日线上确认一个想法有没有证据，不连接券商、不产生下单。所以走到最后一步，你得到的是一套「经过验证、正在被观察」的规则，而不是一个自动赚钱的程序。

## 第 0 步：启动系统，把行情准备好

启动方式二选一，见 [README 启动一节](../README.md#启动)：本机装 Python/Node 跑源码，或者用 Docker Compose（推荐直接拉已发布镜像）。启动后在浏览器打开 `http://127.0.0.1:5173/aquest`。

第一次打开先去**本地行情**（`/market-data`）：

1. 看仓库状态：已覆盖的日期范围和品种数量。全新部署这里是空的；
2. 点「同步」增量拉取到最新交易日。首次全量会慢一些，等它跑完；
3. 有离线通达信数据时，可以用文件导入（`.day` 文件）补录；
4. 之后如果怀疑某段行情有洞（缺口、异常价），先点「开始检查」跑一次只读体检，再决定要不要修复重下。

关于数据的边界，一开始就记住：**只有 A 股日线**（主板、科创板、创业板），没有分钟数据；当日未收盘的行情是未定稿的，不参与筛选和回测。所以盘中跑出的结果少最后一个交易日是正常的。

## 第 1 步：认识三条贯穿全站的规则

这三条决定了所有页面的行为，来自用户手册的「全站共通的三条口径」，值得先背下来：

1. **只做 A 股日线。** ETF/基金、指数、债券、B 股都不进候选池。
2. **信号收盘确认、次日成交。** 所有回测默认按次日开盘价成交，回测收益不等于「今天看到信号就买到」的收益。
3. **凡是看上去不错的发现，先问它能不能被随机解释。** 各处的置换检验、错误发现率校正、「这是第几次试出来的」追问，都是这一条的具体化。这是本工具和「看图选股」最本质的区别。

另外，界面上中文术语后面的小问号悬停会给英文原名和白话解释，看不懂的词先悬停一下。

## 第 2 步：把想法变成一次筛选（公式选股 `/aquest`）

假设你的想法是：看看「突破信号-突破」今天在整个市场筛出多少票。

1. 在「选择信号」区勾选「突破信号-突破」。也可以切到「指标条件」页签，用指标数值（MA20、量比5日、RSI14 等）做大于、小于、上穿、下穿的比较；有通达信公式的话，切「自定义公式」页签直接粘贴解析；
2. 勾多个条件时选好它们的关系：全部满足、任一满足、至少满足 N 个；
3. 选品种范围和板块（不勾就是不限），点「开始筛选」；
4. 结果表给出命中的标的、命中了哪些条件、各排序指标取值。

怎么读结果：**命中数量本身就是第一条证据**。命中几千只说明条件太松，真正决定买谁的是排序而不是条件；命中三五只又不足以配组合。一个能继续往下研究的条件，通常在两者之间。

顺手把结果**存组**：结果表最左侧的「存组」勾一部分票（或整批）保存成股票组。之后回到本页「股票组」面板，能一直回看这批票入组之后涨跌多少、有没有跑赢全市场——这是你想法的第一份事后记录。注意两组数字口径不同：折叠行的「近 1 月 / 近 3 月」所有组同窗口、可以直接比；展开的「入组至今」每组起点不同、只能自己跟自己比。股票组表现不含费用。

这一步只回答「这天谁满足」，**不回答「按它买能不能赚」**——那是接下来两步的事。

## 第 3 步：验证它是不是运气（买卖条件研究 `/condition-research`）

筛选告诉你今天谁命中，条件研究回答更关键的问题：这条条件历史上的盈亏差别，是真的规律还是运气。

1. 设置基础买入规则（可以只用一个内置信号起步）；卖出侧可以留空，勾「持有到期末」表示买入后拿到最后一天；
2. 选品种范围、日期区间、持有天数和交易费用，点开始挖掘；
3. 系统逐只股票独立回测，从「盈利的交易和亏损的交易差在哪」里挖出候选阈值条件，按证据强度排序。

读结果时盯三个地方：

- **三条证据是否同向**：信息系数（指标本身有没有预测力）、信息系数的信息比率（准头稳不稳）、分段同号（是贯穿始终还是某段行情的运气）。三条同向才算证据充分，页面会对不同向的明确降级并写明原因；
- **置换检验 p 值**：原始 p 和校正后的 p 都会给出，校正考虑了这一次运行挖了多少个条件——挖得越多，越容易撞上看起来显著的；
- **「前 N 名胜率」**：模拟真实组合「先筛条件再按排序取前 N 名」的样本。全池胜率再高，槽位里真正买到的那几只不行就没意义。

看到靠谱的候选就勾选，**追加到基础规则上再跑一次**确认提升还在，然后点「用这套规则去跑组合回测」，把买卖规则、排序规则和槽位数一起带过去。

两个新手常犯的错，页面会提醒但不会拦你：同一段行情上反复挖，挖出来的结果高度重叠，别把反复试出来的「显著」当新证据；挖之前先想想这个方向有没有道理（波段研究 `/swing-research` 可以帮你在数据里找候选方向，因子检验 `/factor-test` 可以先确认单个指标有没有预测力）。

## 第 4 步：配上组合，算扣费后的真实收益（组合回测 `/portfolio-backtest`）

从条件研究带过来后，补齐组合参数：

1. 排序指标和方向（同等条件下先买谁）、持仓槽位数；
2. 初始资金与交易成本（佣金、最低佣金、印花税、滑点）；
3. 建仓方式、调仓频率（每日/每周/每月）、成交方式（默认次日开盘）；
4. 「数据范围」里默认排除 ST / *ST / 退市标的。

跑完看四样：扣费后的**净收益**、**最大回撤**、**胜率和盈亏比**、**逐笔成交明细**（每一笔为什么买、为什么卖，都能对上规则）。

对结果保持两点清醒。其一，回测有两个已知的单向偏乐观假设：没有涨跌停不可成交的判断（涨停日也按买进算了），也没有停牌判断——被挑中的往往正是最容易撞涨停的强势股，所以实盘大概率比回测难看。其二，这一版结果只代表这段行情，别急着下结论：同一套规则换个区间重跑、或者先用**策略适配性**（`/strategy-fitness`）看看它在每只票上训练/验证/测试三段是否都走得下去，都是更稳的习惯。

确认可用之后，把这套配置**保存成策略**——这是下一步的前提。

## 第 5 步：从今天起往前看（策略追踪 `/strategy-tracking`）

回测说得再好，都是它在没见过的数据上灵不灵的问题。策略追踪就是干这个的：

1. 在策略列表里对刚保存的策略执行**上线**。上线日取行情库最新可用交易日，观察账户从初始资金、空仓开始，规则从此冻结；
2. 之后不用手动操作，每个交易日收盘后系统自动重算（会先确认没有正在跑的行情任务）；
3. 看观察曲线、研究段绩效参考和衰减比。**观察段太短时页面会明确标注，这时候不要急着下结论**——谈显著性需要的观察期比直觉长得多（年化夏普 0.6 的策略大约要七八年），那是提醒你再等等，不是判策略死刑。

规则上线后不能改：改了就不是样本外了。想试新参数，另开一个追踪。

## 第 6 步：把过程留下来

- **候选库**（`/candidate-library`）：条件研究挖出的候选带着完整证据快照持久化在这里，可以采纳、淘汰，或「发布」成策略。发布前重新核对一遍当时的证据是值得的；
- **回测历史对比**（`/history-compare`）：同一个想法改了几版，勾两到五条历史记录叠绘归一化曲线、并排关键指标，看是在变好还是只是在随机波动；
- **标的检验台**（`/instrument-lab`）：选股结果里冒出一只不认识的票，用它看三个读数——指标在这只票自己历史上的位置、某套规则在它身上的回测、已通过检验的条件今天有没有触发。单票样本极少，它是查看，不是证明。

## 进阶路线

基础路径走通之后，按需求扩展：

| 想做的事 | 页面 | 动手前要知道的 |
|---|---|---|
| 还没有成形想法，让系统自动搜参数 | 策略实验室（`/strategy-lab`） | 榜单第一名天然带挑选偏差——它是在同一批数据上从成百上千个候选里挑出来的，留出段成绩不能当未来预期。用「回填」带回组合回测人工复核 |
| 只关心一只票，逐股深挖买卖信号和止盈止损 | 个股研究（`/individual-research`） | 单票历史研究，结论不能推广到其他股票；留出段只复核最终候选 |
| 全市场每只票各配一套策略，每天看信号 | 全市场策略池（`/strategy-pool`） | 每只股票都要跑完整研究流程，几千只股票需要很长时间。先单只跑通，再上全市场；中断后用「增量更新策略池」接着跑，别动不动清空重建 |
| 事后解释这次赚亏在哪 | 因子归因（`/factor-attribution`） | 它是解释不是预测；要证明因子可用，拿去因子检验做前瞻检验 |

## 新手最常踩的六个坑

1. **把一次筛选当验证。** 公式选股只回答「这天谁满足」，盈利与否要靠条件研究和组合回测；
2. **把回测年化当未来预期。** 回测有两个已知的偏乐观假设（无涨跌停/停牌约束），且换一段行情结果可能完全不同；
3. **在同一段数据上反复挖。** 反复试出来的「显著」不是新证据，条件研究页会提示你重复挖了几次；
4. **只看结果不看边界。** 每个页面都写明「它不能回答什么」，那是刻意写的，不是免责套话；
5. **追踪上线后改规则。** 改了就不是样本外，试新参数另开追踪；
6. **上来就对全市场清空重建。** 全市场策略池一次全量要跑很久，先单只股票走通全流程，确认口径符合预期，再扩大范围。
